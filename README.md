# معرض أعمال تصميم بصري

موقع معرض أعمال عربي باتجاه RTL، مبني بـ HTML وCSS وJavaScript دون إطار عمل أو اعتماديات بناء. يتضمن تصفية للمشاريع، معاينة تفاعلية، قائمة مناسبة للهاتف، وروابط تواصل قابلة للضبط.

## تشغيل الموقع محليًا

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تخصيص البيانات

- عدّل الاسم والتخصص وروابط التواصل في `site-config.js`.
- بطاقات المشاريع الثلاثة موجودة في `index.html` ويمكن تعديل العناوين والتصنيفات والوصف.
- المعاينات المرئية الحالية مرسومة بـ CSS كعناصر مؤقتة، وليست صورًا مأخوذة من ملفات PDF المرفقة. استبدلها بصور صفحات الأعمال الأصلية قبل إرسال الرابط للعملاء.
- بعد توفر صور الأعمال، ضعها في مجلد `assets/works/` واستبدل محتوى أزرار `.project-art` بها.

## نشره عبر GitHub Pages

المستودع ثابت وجاهز للنشر. لتفعيل رابط عام من GitHub:

1. افتح **Settings → Pages** في المستودع.
2. ضمن **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `arena/01a0ff01-yemendv` والمجلد `/(root)`، ثم اضغط **Save**.
4. بعد اكتمال النشر سيظهر الرابط في إعدادات Pages. الرابط المتوقع لهذا المستودع: `https://sbdh1285.github.io/YemenDV/`.

كل المسارات نسبية، لذلك يعمل الموقع داخل مسار المستودع أيضًا.
